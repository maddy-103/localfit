# LocalFit Figma package

This folder is a hand-off package, not a source of app behaviour. Token and icon files are generated from `src/styles/tokens.ts` and `src/components/icons/`, so design and code cannot drift apart. No `.fig` file, Figma API call, or API token is included.

## Files

| Path | What it is |
| --- | --- |
| `design-tokens.json` | Tokens Studio / W3C tokens. Generated by `npm run tokens`; never edit by hand. Groups: `color`, `spacing`, `borderRadius`, `boxShadow`, `fontFamilies`, `fontSizes.desktop`, `fontSizes.mobile`, `lineHeights`, `letterSpacing`, `motion`, `sizing`, `typography.desktop`, `typography.mobile`. |
| `frames.json` | 55 M-priority screens from the sitemap. Each entry has `id`, `name`, `route`, `role`, `priority` and `widths: [360, 768, 1440]`. |
| `screens/*.svg` | 32 deterministic reference frames: the 10 screens below at 360 and 1440 px, plus alternate states. Every layer has a kebab-case id; text uses the THEME heading/body fonts at ≥16 px; photos are tone rectangles; controls have ≥44 px hit areas. Generated by `npm run figma:screens`; do not edit by hand. |
| `icons/*.svg` | One 24×24 SVG per icon in `src/components/icons/` (34 icons). Generated by `npm run tokens`. |
| `components.md` | Checklist of the 38 UI primitives and their variants/states for building Figma components by hand. |

Screens with generated frames: `buyer/home`, `buyer/category`, `buyer/product`, `buyer/cart`, `buyer/checkout`, `buyer/track`, `buyer/trial`, `rider/drop`, `shop/listing-new`, `admin/disputes-detail`. Alternate states cover empty cart, enabled/disabled pay button, ending trial timer, active rider trial timer, offline shop draft and restricted dispute evidence.

## Import steps

1. Install the **Tokens Studio for Figma** plugin, open your LocalFit file, then run **Plugins → Tokens Studio → Import** and choose `design-tokens.json`. Apply the `color`, typography, spacing, radius and shadow groups to the local sets.
2. Import `icons/*.svg` into a Figma page named **Icons** (File → Place or drag them in). Each icon keeps its kebab-case name.
3. Import `screens/*.svg` into pages named **Screens / 360** and **Screens / 1440**. Each file arrives as a frame with named layers such as `trial-terms-block`, `pay-button-disabled` and `timer-remaining`.
4. Build the components in `components.md` manually, then apply the token styles. Use `frames.json` as the inventory when you create the remaining M screens.
5. Run `npm run check:figma` (also part of `npm run build`) after any token or generator change. It fails if a committed artefact is stale or violates the SVG constraints. To refresh artefacts, run `npm run tokens` and `npm run figma:screens`, then commit them together.

## Fully editable screens from the running app

The SVG frames are spec references. For real text, components and layout, **do not hand-write SVG**. Run `npm run dev`, open each route from `frames.json` at 360 px and 1440 px, and capture the rendered page with the **html.to.design** plugin in Figma. That method produces editable layers from the rendered page, so text, components and auto layout can be reused directly. Layer names from the plugin are generated from the DOM and need tidying afterwards — rename them to the kebab-case ids used here so the frames remain searchable and consistent with the tokens and component checklist.

## Known mapping limits

- THEME.md specifies the paid font **Integral CF Bold**, with **Archivo** (width 125, weight 900) as the no-licence substitute. Tokens export the Archivo family name; the paid font can be swapped in Figma once licensed.
- `clamp()` type sizes are exported as fixed desktop and mobile ends, because Figma cannot import `clamp()`.
- `letter-spacing` values are converted from em to px at a 16 px base; no explicit tracking token exists in the CSS.
- Reduced motion and the Archivo width axis are behaviours/features, not token values, so they are documented in `components.md` rather than exported as tokens.
